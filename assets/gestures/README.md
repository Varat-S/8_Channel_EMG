# Gesture display images

Save the five user-provided hamster images in this folder with these exact names:

| Model label | Filename | Supplied image order |
|---|---|---:|
| `peace` | `peace.png` | 1 |
| `rest` | `rest.png` | 2 |
| `fist` | `fist.png` | 3 |
| `thumbs_up` | `thumbs_up.png` | 4 |
| `index_thumb` | `index_thumb.png` | 5 |

PNG, JPEG, and WebP contents are supported by Pillow, although keeping the `.png`
names makes the mapping unambiguous. Images are resized to fit without changing
their aspect ratio.
