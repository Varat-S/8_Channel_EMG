Automatic protocol

  1. Visual calibration: follow seven prompts with a vertical forearm, then the same seven with a horizontal forearm.
  2. Baseline: show a relaxed, naturally grouped hand for five seconds.
  3. Capture: hold any recognized pose. A stable label starts its synchronized EMG segment automatically.
  4. Release: return to neutral, then repeat in any order. Automatic capture for a pose stops at its displayed target.

Important: vision labels posture, not muscle relaxation. Review the saved data before using it as scientific ground truth.
